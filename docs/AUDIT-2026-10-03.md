browser crash → sesi baru me-reset ID tab → tab user ber-ID sama menampilkan

tab user ditutup. Akar: cabang `'failed'` mengasumsikan "ID tercatat ⇒ pasti tab kami",

`origin=''`, error page → `'foreign'` (tidak pernah ditutup). Hanya kecocokan marker
positif yang boleh menutup di jalur `''`. `npm run check` bersih, 58 PASS.

## Yang terverifikasi BENAR (kekuatan utama)

- **Token hygiene:** hanya di header `Authorization`; `#redact` di semua error dinamis;
  `redactConfig` untuk tampilan; import settings membuang token file.
- **Enkripsi:** salt & IV acak per enkripsi; AAD mengikat semua parameter; decrypt
  mengautentikasi sebelum data dipakai; `assertUploadSafe` tak bisa di-bypass;
  public+plaintext selalu ditolak (double-enforced).
- **Upload verification:** re-download + bandingkan sha256 & git blob sha; HTTP 2xx
  saja tidak pernah dianggap sukses.
- **Tab safety (dalam-sesi):** tidak ada TOCTOU verify→remove; exactly-once per tab;
  guard menolak array; permit satu-pakai; verdict tak dikenal → fail-closed;
  `restoreSiteData` tak pernah menutup tab pakai-ulang; Stop membersihkan semua tab.
- **Restore:** satu-satunya jalur hapus adalah bookmarks-replace dengan
  `ERR_CONFIRMATION_REQUIRED`; tak pernah tutup window/tab user; extension storage
  allowlist 5 key `bbr.*` (token tidak ikut ter-backup).
- **Dashboard:** mutual exclusion antar tab bekerja; password tak bocor ke state/log;
  `window.__api` tak terekspos ke web (tanpa content_scripts/WAR/externally_connectable);
  clamp storage korup solid; clear fail-closed.
- **Sweep:** background tanpa backup-tanpa-jadwal; komponen tanpa
  `dangerouslySetInnerHTML`/injeksi URL; 15 permission semuanya terpakai;
  tidak ada tes vacuous; docs tidak kontradiksi dengan kode.

## Batasan audit

- Audit kode statis + penalaran; perilaku runtime Chrome (ID reuse, error-page URL,
  `chrome.tabs.create` dengan windowId mati) sebagian mengandalkan pengetahuan

- Klaim platform tak terverifikasi dari kode: `chrome.storage.session` RAM-only,

- Tidak ada fuzzing, tidak ada pengujian penetrasi jaringan, tidak ada review
  kriptografi formal (parameter dinilai dari kode, bukan pembuktian).
