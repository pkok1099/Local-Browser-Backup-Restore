# Agent Skills

- [executing-plans](executing-plans/SKILL.md) — execute an implementation plan incrementally and independently.

- [using-superpowers](using-superpowers/SKILL.md) — at the start of work, identify and use the relevant skills.
- [verification-before-completion](verification-before-completion/SKILL.md) — before declaring work, tests, or fixes complete.
- [writing-plans](writing-plans/SKILL.md) — when requirements involve multiple implementation steps, before changing code.
