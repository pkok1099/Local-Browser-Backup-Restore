# Skill Agen

Folder ini berisi salinan lengkap 21 skill buatan pengguna. Setiap `SKILL.md` disalin dari sumber runtime tanpa penyuntingan. Gunakan indeks ini untuk menemukan panduan yang sesuai; skill tidak berjalan otomatis—baca salinannya dan panggil skill terpasang saat pemicunya berlaku.

- [brainstorming](brainstorming/SKILL.md) — sebelum pekerjaan kreatif, fitur, atau perubahan perilaku; merumuskan kebutuhan dan desain.
- [diagnosing-superpowers](diagnosing-superpowers/SKILL.md) — menyelidiki sesi Superpowers yang bermasalah berdasarkan bukti.
- [dispatching-parallel-agents](dispatching-parallel-agents/SKILL.md) — membagi dua atau lebih tugas independen tanpa dependensi berurutan.
- [executing-plans](executing-plans/SKILL.md) — menjalankan rencana implementasi sendiri secara bertahap.
- [humanizer](humanizer/SKILL.md) — menyunting prosa agar alami tanpa mengubah makna.
- [ponytail](ponytail/SKILL.md) — menyederhanakan pekerjaan kode dan menghindari kompleksitas yang tidak perlu.
- [ponytail-audit](ponytail-audit/SKILL.md) — audit seluruh repositori untuk menemukan over-engineering; hanya melaporkan.
- [ponytail-debt](ponytail-debt/SKILL.md) — mengumpulkan komentar `ponytail:` menjadi daftar utang/penundaan.
- [ponytail-gain](ponytail-gain/SKILL.md) — menampilkan dampak Ponytail dari hasil benchmark.
- [ponytail-help](ponytail-help/SKILL.md) — menampilkan referensi singkat perintah dan mode Ponytail.
- [ponytail-review](ponytail-review/SKILL.md) — meninjau diff khusus untuk kompleksitas yang bisa dihapus.
- [receiving-code-review](receiving-code-review/SKILL.md) — menilai umpan balik review sebelum memutuskan perubahan.
- [requesting-code-review](requesting-code-review/SKILL.md) — meminta review saat tugas selesai, fitur besar, atau sebelum merge.
- [subagent-driven-development](subagent-driven-development/SKILL.md) — menjalankan rencana melalui implementer subagen dengan checkpoint review.
- [systematic-debugging](systematic-debugging/SKILL.md) — mencari akar masalah saat ada bug, tes gagal, atau perilaku tak terduga.
- [test-driven-development](test-driven-development/SKILL.md) — mengembangkan fitur/perbaikan/perubahan perilaku dengan siklus tes gagal-lalu-lulus.
- [using-git-worktrees](using-git-worktrees/SKILL.md) — menyiapkan atau memverifikasi worktree terisolasi sebelum pekerjaan fitur.
- [using-superpowers](using-superpowers/SKILL.md) — di awal pekerjaan untuk mengenali dan memakai skill yang relevan.
- [verification-before-completion](verification-before-completion/SKILL.md) — sebelum menyatakan pekerjaan, tes, atau perbaikan selesai.
- [writing-plans](writing-plans/SKILL.md) — saat kebutuhan mencakup beberapa langkah implementasi, sebelum mengubah kode.
- [writing-skills](writing-skills/SKILL.md) — saat membuat, mengubah, atau memvalidasi skill.
